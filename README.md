Built around \`Qwen2.5-Coder-1.5B-Instruct\` and optimized for constrained GPU environments (such as a free Google Colab NVIDIA T4 GPU instance), this project demonstrates end-to-end applied AI engineering: from dataset ingestion and half-precision (\`FP16\`) GPU memory management to real-time interactive UI deployment using Gradio. --- ## ⚡ Key Features - 🔍 \*\*Vulnerability Root-Cause Analysis\*\*: Explains OWASP Top 10 web vulnerabilities (XSS, SQLi, OS Command Injection, SSRF, Buffer Overflows) in plain language. - 🛠️ \*\*Defensive Code Generation\*\*: Provides safe, parameterized, and sanitized code patches across Python, JavaScript, and C/C++. - ⚡ \*\*GPU FP16 Optimization\*\*: Leverages 16-bit floating-point precision on CUDA to process 1.5B parameters efficiently without Out-Of-Memory (OOM) errors. - 🎯 \*\*Domain-Tailored System Persona\*\*: Guided by a specialized system persona trained on instruction-tuning cybersecurity datasets. - 🌐 \*\*Interactive Web GUI\*\*: Instant browser interface via Gradio public tunnel sharing. --- ## 🏗️ Architecture &amp;
